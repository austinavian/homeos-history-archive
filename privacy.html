Privacy policy

Effective October 10, 2026. This policy describes the personal HomeOS History Archive application maintained by austinavian.

Data accessed and purpose

The application uses the Google Drive API to store and retrieve the owner's archive files and their names, identifiers, sizes, checksums, and folder metadata. Archive content can include Home Assistant state history, events, attributes, device and entity metadata, log and trace excerpts, original exports, and native database snapshots. Such content may reveal private household activity.

Google authorization currently requests full Drive access to use an existing archive folder. The application targets a dedicated archive folder through its configuration. This folder restriction is an application behavior, not a restriction on the OAuth permission itself. Unrelated Drive documents are not intentionally accessed or deleted.

Storage and retention

Archive files are stored in the owner's Google Drive. Local computers retain collection spools, source snapshots, derived indexes, and bounded query caches as needed for collection, verification, and retrieval. Native snapshots can include data beyond the records displayed by the archive viewer. Original source timestamps and payloads are preserved.

The archive is designed to keep the newest history within 256,000,000,000 bytes. The oldest verified archive-owned objects may be deleted at that cap. This is not a promise of permanent retention. Local staging and cache files are removed according to verification and cache limits; source copies may remain during restoration validation.

Credentials and access

OAuth tokens and other credentials are stored privately on the owner's local computer, outside the archive and this website. Archive queries require authentication. Public documentation and its source repository contain no archive data or credentials.

Sharing and AI queries

The application does not sell archive data, use it for advertising, or send it to an analytics service. Google processes the files stored through Drive under its own policies. The owner may explicitly request historical queries through connected tools, including ChatGPT; returned records are then shared with the selected tool or provider and are subject to that provider's policies and the owner's account settings. The archive does not automatically publish its contents or use Google user data to train general-purpose AI models.

HomeOS History Archive's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Control, deletion, and contact

The owner can stop the worker and revoke access in Google Account connections. Revoking access prevents future API access but does not delete existing copies. To remove stored history, the owner must also delete the dedicated archive files and retained local copies. Contact the maintainer through the linked GitHub profile; do not submit private records or credentials in public issues.

This documentation website

These static pages use no application cookies, tracking scripts, sign-in forms, or analytics. GitHub Pages hosts the website and may process visitor connection information under GitHub's privacy statement.

Changes to data practices will be reflected on this page.
