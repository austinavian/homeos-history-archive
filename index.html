HomeOS History Archive

A personal Home Assistant history archive maintained by austinavian. A local Mac worker preserves original historical exports, event records, and native database snapshots in a dedicated folder in the owner's Google Drive.

The app uses Google Drive to upload and verify archive files, recover its archive catalog, retrieve historical records on demand, and expire the oldest verified archive-owned objects when the configured storage cap is reached. Authenticated archive views support historical queries beyond Home Assistant Recorder's normal retention window.

Why Google Drive access is requested

The existing archive folder was created separately, so the current rclone configuration requests full Google Drive access. That permission can technically access files throughout the authorized account. The app's configured operations target its dedicated archive folder; it does not intentionally read, modify, or delete unrelated Drive documents.

This is a personal tool, not a public archive service. This public website contains documentation only. It provides no access to the archive, Home Assistant, or credentials.

Read the privacy policy and terms of use before authorizing access. Contact the maintainer through the linked GitHub profile; do not post credentials or household history publicly.
